# Analysis of single cell RNAseq data of murine nasal mucosa during influenza infection

# 1 | Introduction
Single cell RNA sequencing has allowed for the specific tracing of particular cell lineages within tissues and organs (Saliba et al., 2014). As such, it is being used increasingly in applications wherein cell-to-cell variability must be explored. Relevantly, a study by Kazer et al. (2025) utilized single cell RNAseq to characterize the cell composition of tissues within the murine nasal mucosa during influenza infection. 

The nasal mucosa is both the site of infection and defense for viral infections (Tamura & Kurata, 2004), and as such, patterns in the expression of cell types within this region elucidate the mechanisms invoked during the immune response. Given the heterogeneity of cell types within the nasal mucosa, their longitudinal responses during infection must also vary. For instance, Kazer et al. identified epithelial subsets that responded to viral infection, characterizing a new subset of epithelial cells as KNIIFE cells (2025).

Monocyte recruitment is expected to increase following infection (Kazer et al., 2025), and it is thus postulated that expression of genes in this cell type will differ between a naïve and infected state. Differential expression analysis of this cell cluster will be performed via DESeq2, which has been shown to account for variation between replicates via its implementation of a negative binomial distribution (Love et al., 2014). As such, pseudo-bulking will be performed to create biological replicates to account for this.

In this project, a single cell RNAseq dataset derived from murine nasal mucosa will be comprehensively analyzed via several methods, including visualization of UMAP clusters, annotation of cell types, differential expression analysis, and functional enrichment analysis. The latter two methods will focus on a subset of monocytes, where expression of genes will be compared between a naïve sample group and an infected group.


# 2 | Methods
All R code outlined in the following sections can be accessed [here.](scripts/RNAseq_analysis.R)

## 2.1 | Data Description
Data was obtained as a Seurat object, taken from single cell RNAseq data generated by Kazer et al. (2025). The dataset consists of RNA counts from the nasal mucosa of mice, sampled from three different regions (e.g. respiratory mucosa, olfactory mucosa, and lateral nasal gland). Mice were sampled at five different timepoints: naive (pre-infection), and 2, 5, 8, and 14 days post-infection. The pre-processed Seurat object consisted of 156,572 samples and 25,129 genes. Overall analysis and clustering was conducted on every tissue type present in the dataset.

## 2.2 | Quality Control
Quality metrics were assessed according to the recommended Seurat pipeline (Hao et al., 2024) using Seurat v5.4.0. Mitochondrial percentage was added to the Seurat object to filter out potential low-quality or dying cells. Cutoff thresholds for the number of unique genes, molecules, and mitochondrial percent were visually determined using violin plots (Fig. 1). The Seurat object was subset by filtering out unique feature counts less than 750, and cells that have more than 10% mitochondrial counts. Post-filtering, 148,381 samples remained in the object.
```
seurat <- subset(seurat, subset = nFeature_RNA > 750 & percent.mt < 10)
```

## 2.3 | Normalization, Feature Selection, Scaling, and UMAP Clustering
Normalization, feature selection, and scaling were performed via the SCTransform workflow, which fits a regularized negative binomial model. This accounts for the variability in the number of RNA molecules within cells during the normalization process. The glmGamPoi package v1.22.0 was used to speed up performance of this step. All defaults were used, except ncells was set to 2000 and conserve.memory was set to TRUE to optimize memory efficiency. The SCTransform method returned an SCT assay with 3000 variable features selected.
```
seurat <- SCTransform(seurat, ncells = 2000, conserve.memory = T)
```
Following this, a PCA was conducted on the scaled data using the selected variable features. Dimensionality of the dataset was determined using an elbow plot (Fig. 2), with k = 33 chosen as the value. 
```
seurat <- FindNeighbors(seurat, dims = 1:33)
seurat <- FindClusters(seurat, resolution = 0.6)
seurat <- RunUMAP(seurat, dims = 1:33)
```

Clustering was performed via FindNeighbors and FindClusters, which used 33 principal components and a resolution of 0.6, respectively. The resolution was chosen based on the method described by Kazer et al. (2025). Non-linear dimensional reduction was then visualized via UMAP, generating the unannotated cluster plot with 40 clusters (Fig. 3).

## 2.4 | Cluster Annotation
Clusters were annotated in one of two ways: automatic annotation via SingleR v2.12.0 and manual annotation through referencing literature (Kazer et al., 2025) and web sources such as CellMarker 2.0 (Hu et al., 2023) and PanglaoDB (Franzén et al., 2019). Two reference datasets were used for automatic annotation, these being MouseRNASeqData (Benayoun et al., 2019) and ImmGenData (Heng et al., 2008). The former includes annotations for 28 subtypes of cells, while the latter has annotations for 20 broad types of mouse immune cells. SingleR was run with all defaults, and the detection method used was set to Wilcoxon, as it is more effective than the classic method, which is intended for bulk transcriptomic data. 
```
# Sample code for annotation with celldex references
ann_mrs <- SingleR(
  test = as.SingleCellExperiment(seurat),
  ref = MouseRNAseqData,
  labels = MouseRNAseqData$label.fine,
  de.method = "wilcox")
```
Manual annotation was performed by running FindAllMarkers with the entire dataset. The logfc.threshold and min.pct thresholds were set to the Seurat v4 values (0.25 each) to speed up computation. The Wilcoxon method was again used for its suitability to single cell data. The top 5 markers for each cluster were selected according to their adjusted p-value and average log2foldchange, and these markers were cross-referenced with papers and databases to produce two annotations: one that was literature-based, and one that was based on online reference databases. The .csv files generated for this step can be found in the [supplementary material.](supplementary/) Four clusters were annotated as the same cell type, so further analysis was done by finding markers that differentiated each cluster from one another. However, no markers were found that could disambiguate each cluster.
```
markers_all <- FindAllMarkers(seurat,
  only.pos = T,
  logfc.threshold = 0.25,
  min.pct = 0.25,
  test.use = "wilcox")
```


## 2.5 | DE Analysis of Naive vs Infected Groups
To conduct differentiation expression analysis, the cluster annotations generated by manual annotation were used. The dataset was first pseudo-bulked to account for within-sample correlation, which inflates p-values and produces many false positives. Cells from each sample were grouped together by cell type and time, producing summed gene counts of cells for each cell type. 
```
seurat_bulk <- AggregateExpression(seurat, assays = "RNA", return.seurat = T, group.by = c("mouse_id", "time", "cell_type"))
seurat_bulk$cell_time <- paste(seurat_bulk$cell_type, seurat_bulk$time, sep = "_")
```
For this DE analysis, the cluster of IFN-stimulated monocytes was chosen, and this cell type was analyzed at the naive timepoint and 5 days post-infection. It was theorized that this group of cells should show different expression profiles pre-infection and during infection as they are directly involved in the immune response. After pseudo-bulking, FindMarkers was used with DESeq2 v1.50.2, which is typically used for pseudo-bulked data. Genes were then filtered by significance (adjusted p-value < 0.05) and a log2FC threshold of 1, with log2FC > 1 considered as upregulated, and log2FC < -1 as downregulated. The expression of three upregulated and three downregulated genes were then visualized with violin plots. The visualization was repeated with the non-pseudo-bulked data to show the effects of within-sample correlation.
```
seurat_DE <- FindMarkers(seurat_bulk,
  ident.1 = "IFN-Stim Monocytes_D05",
  ident.2 = "IFN-Stim Monocytes_Naive",
  test.use = "DESeq2")
```

## 2.6 | GSEA and ORA of Differentially Expressed Genes
Functional enrichment analysis was conducted on the subset of IFN-stimulated monocytes at the naive and day 5 timepoints using clusterProfiler v4.18.4. Gene set enrichment analysis (GSEA) of GO biological processes and KEGG pathways was conducted by first constructing a list of ranked genes. Genes were ranked by a metric combining both p-value and log2FC. For over-representation analysis (ORA), a list of significant genes was obtained by filtering for genes with adjusted p-value < 0.05 and an absolute log2FC value > 1. The list of genes generated by DESeq2 was used as the background set. Upregulated and downregulated genes were compared using the compareCluster function.
```
# Sample code for GSEA with gene ontology (GO)
gsea_GO <- gseGO(
  geneList = ranked_genes,
  OrgDb = org.Mm.eg.db,
  ont = "BP",
  keyType = "ENTREZID",
  by = "fgsea")

# Sample code for ORA with GO
ora_GO <- compareCluster(ENTREZID ~ expression,
  data = sig_genes,
  fun = "enrichGO",
  OrgDb = org.Mm.eg.db,
  universe = seurat_DE,
  keyType = "ENTREZID",
  ont = "BP")
```


# 3 | Results


## 3.1 | UMAP Clusters
Non-linear dimensional reduction with UMAP showed that cells co-localized into 40 clusters, which may or may not represent biologically distinct cell types. Clusters were annotated either automatically or manually, producing similar annotations at the broad level, but differing in their level of specificity. Annotations of cell types done automatically via SingleR and reference datasets captured broad lineages, but were unable to resolve specific subgroups within clusters (Fig. 4).  For instance, while MouseRNAseq Data could label the cluster of B cells and endothelial cells, it was unable to annotate several clusters as one specific cell type. Rather, these clusters were annotated as a mixture of multiple cell types, and not as distinct clusters. Moreover, as would be expected, annotation with the immune cell dataset differentiated between T and NK cell subtypes, as well as granulocyte populations. Conversely, it was less specific with epithelial cells, and was unable to annotate neuronal populations as they were not present in the reference. Diagnostic heatmaps demonstrate that automatic annotations for cell types present in the reference datasets were fairly accurate [(supplementary figures 1 and 2)](figs/)

Manual annotation was able to separate clusters into distinct cell subtypes, as well as identify clusters that were unlabeled by automatic annotation (Fig. 5). All 40 clusters were annotated, although some clusters found via UMAP were annotated as the same cell type. For instance, clusters 4, 5, 13, and 17 from the unannotated UMAP (Fig. 3) were annotated as Dlg2+ olfactory sensory neurons (Fig. 5). The manual annotations also validate the automatic annotations, with most clusters annotated as the same cell type. The manual annotations represent the most accurate and specific representations of the clusters, confirming that the UMAP clusters represent distinct cell types. For example, the large group of cells on the right are subtypes of olfactory sensory neurons, while the cluster at the bottom reflect populations of neutrophils in different stages of maturity. Clusters that were unlabeled in the automatic annotations are revealed to be populations of mural cells, sustentacular cells, glandular cells, and goblet/secretory cells.

## 3.4 | GSEA and ORA
Gene set enrichment analysis (GSEA) and overrepresentation analysis (ORA) revealed biological processes and pathways enriched in the upregulated and downregulated genes in IFN-stim monocytes (Fig. 11, Supplementary Fig. 3). Although both methods varied in implementation, they found the same biological processes and pathways enriched in the samples. Biological processes related to activation of the innate immune response and viral response, as well as the recruitment of interferons/cytokines were enriched in the upregulated group. Similarly, pathways related to efferocytosis, signaling pathways, osteoclast differentiation, and response to viruses are upregulated. Conversely, processes related to the negative regulation of cell-mediated immunity and toxicity, as well as translational and metabolic processes, are downregulated. Pathways that are enriched in the downregulated group include ribosomal, thermogenesis-related and spliceosome-related pathways.

# 4 | Discussion

## 4.1 | Automatic and Manual Annotation of Clusters
Annotation of cell clusters was performed in two ways, highlighting the strengths and weaknesses of both methods, but also demonstrating their complementarity. Automatic annotation can only produce a broad overview of cell types, limited by the annotations in the reference datasets used. A more comprehensive or curated dataset could alleviate this issue, which requires a considerable amount of time invested. With current reference datasets, automatic annotation is still vastly faster than manual annotation. However, what manual annotation lacks in speed is offset by its accuracy and specificity, though this is also affected by the quality of reference databases and literature, as well as the skill of the annotator. Together, however, automatic and manual annotation provide a workflow that combines the advantages of the other. Automatic annotation can be used to provide a general overview of the cell types, while manual annotation can provide more resolution to specific cell subtypes and populations.
Notably, annotation with literature was able to identify rare lineages of cells, such as the Krt13+ or KNIIFE cells discovered by Kazer et al. (Fig. 5). Moreover, it also revealed that some clusters of cells were grouped together not solely because they represent the same cell type, but because represent a population of related cells. For example, a cluster of cells was identified to be OBP-related cells (Fig. 5). In other words, they represent a group of cells of different subtypes and lineages (e.g. epithelial, endothelial, fibroblasts) that were enriched in odorant binding protein (Supplementary Figure 4). As such, they do not reflect a specific lineage, and were instead grouped together as they expressed markers associated with odorant binding proteins (OBPs). This corresponds to the fact that the nasal mucosa epithelium is enriched with OBPs (Strotmann & Breer, 2011), and this cluster likely reflects cells that produce or are in close contact with these proteins.
While dimensional reduction with UMAP produced 40 clusters, some clusters were annotated with the same cell type. This may be due to specificity issues, where annotations are limited by the lack of relevant reference markers, or it could be due to the choice of resolution initially chosen for clustering. In either case, unannotated UMAP clusters may not represent distinct cell subtypes, so manual annotation must still be performed to validate the clusters.

## 4.2 | Feature Plots of Lineage Markers
Feature plots of canonical markers for neurons, epithelial cells, immune cells, and endothelial cells support the manually annotated clusters (Fig. 6). Expression levels of the markers generally mapped well to the annotated regions, although there were some exceptions. For one, Epcam was expressed in several clusters not annotated as epithelial cells, likely related to its multi-functionality in cell adhesion, migration, and differentiation (Gires et al., 2020). Notably, it was expressed in regions with immature and differentiating cells (Fig. 5), such as the differentiating olfactory sensory neurons and the B cell progenitors. Similarly, while the epithelial cell markers Foxj1 (ciliated cells) and Ltf (serous cells) map well to their respective cell subtypes, they are also expressed in clusters related to epithelial cells. Foxj1 has moderate expression in the cluster of olfactory sensory neurons (Fig. 5, Fig. 7), which are known to have multi-ciliated dendrites (McClintock et al., 2020). Ltf is shown to have high expression in the cluster annotated as immature neutrophils, potentially reflecting its association with neutrophils (Kovacic et al., 2014).

## 4.3 | Differential Expression of Genes in Naïve vs Infected Groups
Violin plots of the upregulated and downregulated genes demonstrate that pseudo-bulking was able to account for within-sample correlation (Fig. 9, Fig. 10). While pseudo-bulk sums the counts of cells of specific types within biological replicates, single cell methods treat cells as statistically independent. This has the drawback of producing inflated p-values as well as false positive (Junttila et al., 2022). As such, while Cd209d was found to be a statistically significant downregulated gene in the pseudo-bulked test, it would have been missed in a per-cell test (Fig. 9, Fig. 10).
The upregulated and downregulated genes found via pseudo-bulked DESeq2 analysis also reflect the biological state of the cell when it is infected. Interestingly, Ly6c2 appears to have no effect in the immune response and is simply differentially expressed in monocytes (Morimoto et al., 2022). As such, it is upregulated in the infected group as monocytes are more prevalent. Gda encodes guanine deaminase, which converts guanine to xanthine, though its connection to an infected state is unknown (Paletzki, 2002). Slfn4 is involved in the inhibition of T cell proliferation (Ding et al., 2016) and the regulation of interferon response (Fischietti et al., 2018). In contrast, genes such as Rnd3, involved in neuronal differentiation (Dong et al., 2017) and Cd209d, involved in viral sensing (Gopal et al., 2025), are downregulated in the infected state. The former could be due to a shift away from unrelated processes during infection, while the latter could reflect a shift towards battling the infection rather than recognition.

## 4.4 | Gene Set Enrichment Analysis
The GSEA reveals changes in the metabolic processes and pathways invoked by monocytes during an infected state. Processes related to the activation and regulation of the innate immune response are heavily upregulated (Fig. 11), as would be expected. Conversely, processes related to the upkeep of cellular machinery and day-to-day activity, such as ribosome biogenesis and translation are downregulated. Similarly, pathways related to thermogenesis, the ribosome, and spliceosome are also downregulated (Fig. 11). This reflects the reallocation of cellular resources towards the immune system response. Moreover, processes related to the negative regulation of NK-cell and T-cell mediated immunity are downregulated (Supp. Fig. 3). In other words, processes related to the adaptive and innate immune responses are activated during an infected state (Vojdani et al., 2024). This is supported by the upregulated KEGG pathways, which relate to the immune response. For instance, efferocytosis and lysosome biogenesis are upregulated, corresponding to the apoptosis of viral cells (Ge et al., 2002). Moreover, the upregulation of osteoclast differentiation reflects the role of osteoclastogenic cytokines during the immune response (Charles & Nakamura, 2014).
